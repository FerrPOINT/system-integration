# Проверки сервиса

`e2e/` проверяет запущенные приложения через штатные точки входа.
`load/` отвечает за отдельный прогон [NF08](load/README.md).
Модульные тесты остаются в своих приложениях.

- Связывайте проверки с [планом приёмки](../docs/test-cases.md). Для прав,
  повторов и восстановления проверяйте исход и сохранённые данные.
- Для сквозных и нагрузочных сценариев используйте выделенные тестовые
  данные. Логи, снимки и результаты кладите в игнорируемый `results/`.
- Команды и адреса для запуска перечислены в [README проверок](README.md).
