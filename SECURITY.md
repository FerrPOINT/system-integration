# Безопасность

Сервис разрабатывается для локального тестового окружения.
[Текущая стадия](docs/current-stage.md) отделяет выполненные проверки
от оставшейся приёмки. Данные тестового стенда должны быть вымышленными.

- Сервер проверяет сессию, роль и доступ к записи.
  Инициатор получает доступ к своим заданиям, оператор — к разбору обмена.
  Для запросов изменения через браузер требуется CSRF-токен. Матрица доступа задана
  в [аналитике](docs/analysis.md#задание-и-роли).
- У эмулятора собственная роль и БД. Управление сбоями
  включается профилем `test-faults` и доступно только в тестовой сети.
  Сценарии описаны в [демонстрации](docs/analysis.md#демонстрация).
- Передавайте секреты через окружение. Храните в репозитории безопасные
  примеры настроек и используйте вымышленные данные. Пароли, ключи,
  cookies и CSRF-токены исключайте из журналов и отчётов.
- Проверяйте права прямыми запросами по TC-08 и отсутствие секретов в
  журнале по TC-14. См. [план приёмки](docs/test-cases.md).

О проблеме сообщайте владельцу проекта приватно. Укажите версию,
затронутый сценарий и ожидаемый результат. Обезличьте приложенные данные.
