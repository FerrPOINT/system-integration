# Frontend

React и TypeScript. Код сценария храните рядом с его экраном. Сервер
определяет доступ, статусы и доступные действия. Для REST используйте
клиент, сгенерированный из [внутреннего OpenAPI](../contracts/internal-api.openapi.yaml).

- Подключайте только используемые компоненты Base. Сохраняйте их происхождение
  и лицензию. Основной сценарий должен работать от 390 до 1440 px и с клавиатуры.
- Устанавливайте зависимости по lockfile и проверяйте сгенерированный
  клиент по [командам README](../README.md#сборка-и-проверки).
