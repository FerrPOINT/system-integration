# Frontend

React и TypeScript. Код сценария храните рядом с его экраном. Сервер
определяет доступ, статусы и доступные действия. Для REST используйте
клиент, сгенерированный из [внутреннего OpenAPI](../contracts/internal-api.openapi.yaml).

- Для общих полей и кнопок используйте локальные компоненты в src/ui; новый компонент сначала ищите в Base. Не дублируйте их нативными элементами и глобальными стилями. Подключайте только используемые компоненты Base. Сохраняйте их происхождение
  и лицензию. Основной сценарий должен работать от 390 до 1440 px и с клавиатуры.
- Устанавливайте зависимости по lockfile и проверяйте сгенерированный
  клиент по [командам README](../README.md#сборка-и-проверки).

- Общие визуальные правила и состояния принадлежат src/ui. На экранах используйте
  Card, PageHeader, FormField, Notice и другие существующие примитивы; CSS экрана
  определяет композицию, а не свою версию кнопок, полей или карточек.
- Brand в src/app/Brand.tsx используется на входе и в оболочке. Происхождение
  и адаптации компонентов перечислены в src/ui/README.md.

- Внешний вертикальный интервал задаёт родительский base-page-stack. Не добавляйте
  margin одновременно в компонент и в контейнер; проверяйте загрузку, ошибку,
  пустое и заполненное состояние на обоих размерах экрана.

- URL владеет фильтрами и страницей: изменения применяются сразу без отправки.
  Кэш, отмена чтений и смена аккаунта описаны в
  [архитектуре](../docs/architecture.md#чтение-кэш-и-повтор-команд);
  при изменении правил проверяйте UI-09–UI-11.

Пагинация синхронизирует измеренный size только с текущим адресом. Маршрутизатор
может уже изменить браузерный URL до применения React-перехода; отложенный
эффект старой страницы не должен отменять новый маршрут или фильтр. Проверка
pathname/search/hash выполняется в единственном владельце usePagination;
не добавляйте задержки и локальные исключения в кнопки перехода.

До 760 px списки и история используют ленту с порциями по 20 записей,
прокруткой документа и IntersectionObserver. React Query владеет всей
последовательностью страниц через useCollectionQuery; не копируйте выдачу
в локальные массивы состояния. Фильтры остаются в URL, page/size принадлежат
desktop-режиму. Ошибка следующей порции сохраняет данные и требует явного повтора.
