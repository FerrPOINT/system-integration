# Общие компоненты интерфейса

Компоненты находятся в shared/ui, общие стили — в shared/styles.
Экраны собирают композицию из этих примитивов и задают только свою сетку.
Сведения об исходном коде и лицензии находятся в [NOTICE](NOTICE.txt) и [LICENSE](LICENSE).

## Компоненты

| Задача | Компонент |
| --- | --- |
| Поверхность, содержимое и заголовок | Card, CardContent, CardTitle |
| Название экрана и действия | PageHeader, ActionGroup, BackLink |
| Поле и подпись | FormField, Label, Input, Textarea, Select |
| Сообщение, загрузка и пустое состояние | Notice, Loading, EmptyState, ErrorMessage |
| Список, страницы и история | Table, PageNavigation, Timeline |
| Подтверждение и форма поверх страницы | Dialog, DiscardDialog |

Добавляйте вариант или экспорт только вместе с реальным потребителем.
Семантические thead/tbody/th/td не требуют пустой React-обёртки.
CardTitle поддерживает asChild, когда экрану нужен определённый уровень заголовка.

Radix управляет focus trap, порталами, Escape и клавиатурой сложных элементов.
Select сохраняет одного владельца FormData/required/reset/disabled. Нативный
контроль внутри компонента не дублируется независимым состоянием экрана.
clsx собирает имена CSS-классов; Tailwind в проекте не используется.

## Оформление и адаптивность

Локальный CSS-префикс — ui-. Палитры и размеры заданы в design-tokens.css.
Тема принадлежит app/shell/theme.tsx; компоненты читают CSS-переменные.
Первый запуск использует тёмную тему, доступны светлая и серая.
Brand один для входа и оболочки.

Внешний вертикальный интервал задаёт родительский ui-page-stack.
Компоненты не добавляют конкурирующие внешние margin. Нажимаемые элементы
сохраняют доступную область и видимый focus; длинные значения сокращаются
в доступной ширине.

На телефоне реестры показывают карточки, на широком экране — таблицу.
PageNavigation работает с известным числом страниц и записей.
FeedStart/FeedFooter отвечают за загрузку частей мобильной ленты и явный retry;
useCollection владеет Query-окном, ограниченным пятью страницами.

## Владельцы состояния

- URL хранит фильтры. Изменения применяются сразу и сбрасывают desktop-страницу.
- Query хранит серверные страницы; компонент не копирует выдачу в свой state.
- Экран задаёт identity восстановления позиции. Общий hook не знает маршрутов
  конкретного ресурса и хранит только изолированные metadata позиции.
- Форма хранит черновик. Команда и последующее обновление данных имеют отдельные
  состояния: повтор обновления не отправляет бизнес-команду заново.
- Ограничения полей генерируются из OpenAPI; shared/lib/form-rules.ts адаптирует
  их к HTML, включая отличие UTF-16 maxlength от Unicode code points.
- Серверные allowedActions определяют допустимые операторские действия.
  Клиентский предикат формы не заменяет проверку прав на сервере.

useFormNavigationGuard использует штатные механизмы маршрутизатора и
beforeunload. Неподтверждённый исход создания сохраняет исходный ввод и ключ;
закрытие предупреждает о потере безопасного повтора.

Проверки компонентов и мобильных коллекций находятся в tests/components;
fixtures не входят в production build.
