# Локальные компоненты Base

`use-media-query.ts` перенесён без изменений из локального набора UI mini-crm
по поручению владельца FerrPOINT. Этот набор основан на Base PDLC 0.3.33,
commit `5b6a3f3b0e538c9e6eb0ed0a7f455dca05bf67de`.
SHA-256 скопированного файла:
`265371dfc84ede43f81b9198e4db02f6655c4515da7d88dd6c0d61fb8f4c51ce`.
Хук используется реестром: узкий экран получает карточки вместо таблицы.
LICENSE и NOTICE сохранены рядом. Остальные компоненты добавляются только
при появлении потребителя. Пакет `@pdlc/ui` не подключён.

## Компоненты и оформление

Select, Button, Input, Textarea, Badge и палитры перенесены из Base PDLC:
services-base/base-modules/ui/src, commit 9a5008a79415110a0d8fdcc8348aa4853dbcc3fc.
Копия локальная, зависимости от пакета @pdlc/ui нет. LICENSE и NOTICE применяются
к скопированному и производному коду.

- Select — однозначный выбор из Base select.tsx; MultiSelect не переносился.
  choice-field.tsx и choice-types.ts сохраняют единственного владельца FormData,
  required/reset/disabled, управление Tab и восстановление фокуса.
  Вложенные платформенные темы не используются: портал наследует переменные корня.
- Input перенесён с заменой пути к локальному cn.
- Button сохраняет Base Slot/asChild и используемые варианты default/outline.
  Textarea использует ручное изменение размера, Badge — четыре используемых тона.
  Неиспользуемые subject-color, autosize, размеры и платформенная локализация исключены.
- design-tokens.css содержит обычные CSS-палитры Base без блока Tailwind @theme.
  controls.css переносит используемые правила Base; полю и пункту меню задан
  минимум 44 px, длинное значение сокращается внутри доступной ширины.
  Горизонтальный отступ 16 px оставляет место между стрелкой и краем.
- clsx собирает имена классов; Tailwind и механизм его слияния здесь не нужны.
  Radix отвечает за выбор, портал и клавиатуру; отдельный самописный dropdown не нужен.

Стили общих элементов принадлежат ui/, разметка экранов и сетки — app/ и features/.
Тема хранится в app/theme.tsx; компоненты читают только CSS-переменные.
Фильтр «Все результаты» имеет явное UI-значение ALL, которое не отправляется в API.
Пустое значение в обязательном действии оператора остаётся placeholder.

## Общие паттерны экранов

Карточки и их содержимое — Card/CardContent/CardTitle; заголовок страницы —
PageHeader; поле, подпись и подсказка — FormField/Label; таблица — Table;
сообщение — Notice; пустой результат — EmptyState; фильтры — Disclosure;
действия — ActionGroup; история — Timeline. Эти реализации перенесены из того же
Base commit. PageHeader использует только обычный заголовок, контекст и действия;
Disclosure — только panel, без неиспользуемого ResourceList row.
CSS-правила выбранных семейств из Base находятся в patterns.css; Tailwind utility
классы заменены эквивалентными обычными CSS-правилами.
Подсказки и required принадлежат FormField, содержимое и side effects — экрану.
BackLink составляет штатные Button и React Router Link.

Brand в app/Brand.tsx один для входа и шапки: Base IconMark и SVG ArrowRightLeft
из уже используемого Lucide. Цвета и размеры знака задаёт Base; текстовых
псевдологотипов и отдельной копии на странице входа нет.
styles.css отвечает за сетки экранов и оболочку. Общие поля, кнопки, карточки,
сообщения, заголовки и история в нём заново не оформляются.
