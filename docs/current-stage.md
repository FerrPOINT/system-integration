## Архитектура и границы

Остались два Spring Boot приложения и PostgreSQL без новых процессов,
кэшей ответов, счётчиков или партиций. Spring Data JDBC читает реестр/карточку/
историю; command/exchange SQL остаётся в JDBC-репозиториях. Domain определяет
переходы, service — сценарий и транзакцию, controller/mapper — HTTP.
Generated OpenAPI interfaces/client появляются только при сборке.

Приняты INSERT RETURNING и одно чтение replay в эмуляторе, bounded fault-map
выбранной пачки, один итоговый task UPDATE за страницу при сохранении
каждого события и полного прироста версии. Добавлены V8 узкого count-индекса
и V9 table-level vacuum scale 0,05. Default in-flight8 вместо 32.
Exact total/REPEATABLE READ, права, атомарность outbox/history/cursor,
конечные попытки, leases/fencing и восстановление сохранены.
История не сворачивается. Пакетная публикация 25 и исполнение 5 сохранены.

Server-prepared вариант захвата очереди отклонён после проверки растущих данных;
рабочий статический Statement адаптирует план без ожидания ANALYZE.
Новый производный счётчик P5 не понадобился для подтверждённого объёма.
Остальные условные механизмы не внедрялись ради формального списка паттернов.

## Ограничения

- Подтверждённая длительная ступень —70×4 на росте 5k→68,9k за 15 мин.
  Точный максимум и неограниченный рост базы не установлены. COUNT остаётся
  линейной работой; прежние 90-прогоны с другим прогревом/наблюдением давали
  накопление очереди и 503. Новый короткий 90 PASS этого не отменяет.
- В NF08 быстрый create означает сохранение. Его интенсивный closed-loop
  поток накапливал очередь: first-attempt p95≈70,5 с, после окна всё исполнено.
  Устойчивость отдельно подтверждена профилями выше.
- Старый J70L1 сохраняет sustainable=false. Диагностический integral по
  event-time предшествует commit и не заменяет квалификацию; точность
  исправлена в тестовом инструменте, пороги не снижались.
- Новые образы не установлены в публичное demo. После закрытия QA проверены
  HTTPS root 200/защищённый API 401 и совпадение index с обычным frontend.
  Публичные образы остались 2e97ce4; это сохранность прежнего runtime,
  не приёмка нового кандидата.
- Свои 4 QA-контейнера, 1 том, 24 старые image tags и 43 временных файла удалены.
  Сохранены 3 итоговых образа и ≈5,6 МБ lossless receipts. Все 11 обычных
  контейнеров сохранили ID/image/StartedAt. Общий build cache не чистился.
