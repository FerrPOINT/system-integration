# Текущая стадия

Реализация SI-01–SI-04 добавлена. Подготовлены обе роли, очередь, независимый
эмулятор, операторские решения и экраны. Сейчас выполняется SI-05 — приёмка
собранного стенда. Полная готовность к сдаче пока **не подтверждена**.
Критерии находятся в [декомпозиции](decomposition.md).

## Проверки 12 ноября 2026 года

| Область | Фактическое подтверждение |
| --- | --- |
| PostgreSQL | Запуск, сохранение после перезапуска и изоляция ролей подтверждены. У приложения, эмулятора и двух тестовых БД отдельные роли и пароли. |
| OpenAPI | Обе схемы валидны. Генерация Java и Fetch-клиента подключена к сборкам. Ошибки используют сгенерированные модели. |
| Серверные тесты | 40 проверок прошли: контракты, задачи, очередь, операторские решения, HTTP ленты и эмулятор. PostgreSQL использован в интеграционных сценариях. |
| Frontend | Orval, TypeScript и production-сборка Vite прошли. Пять тестов HTTP-клиента проходили. |
| Браузер | 12 автотестов прошли на 390 и 1440 px. Добавлена проверка бизнес-отказа и загрузки. Живая IAB-проверка недоступна: Local browser use отключён в настройках Work. |
| Полный Compose | Три образа собраны из исходников, четыре сервиса запущены. Два HTTP smoke прошли. Чистый checkout с новой БД проверяется отдельно. |
| Восстановление | Выполняется runner с пятью этапами и контрольными точками реальной БД. Итоговый отчёт пока не получен. |
| NF08 | Runner и отдельные тестовые БД подготовлены. Замер ещё не выполнен. |
| CI | Workflow подготовлен с PostgreSQL и разными тестовыми ролями. На GitHub не запускался. |

Отчёты тестов и сборок остаются в игнорируемых каталогах. Кандидат
фиксируется в Git перед сборкой контейнеров; их метка
`org.opencontainers.image.revision` связывает образ с исходниками.

## Что остаётся до приёмки

- Проверить чистый запуск SI-00.5 с новой БД.
- Выполнить демокоманду: три учётки, шесть заданий и четыре режима сбоя.
- Повторить расширенные браузерные сценарии и выполнить живую проверку обеих ролей.
- Проверить перезапуски API, БД и эмулятора через recovery runner.
- Выполнить NF08 и собрать фактические показатели и лимиты.
- Закрыть приёмку TC-01–TC-15 и [матрицы требований](requirements.md)
  на окончательной версии, устранив найденные дефекты.

Цель сохраняет все 20 требований и разделы 6–10 исходного ТЗ. Успешные
частичные проверки не означают готовность всего сервиса.
