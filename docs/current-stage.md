Публичный вход: Koara TLS gateway → ограниченный обратный SSH-туннель →
frontend Firebat1. Публичный Compose включает Secure cookie и restart policy.
Порты `19573`, `19580`, `19581` и `19532` на Firebat1 слушают только loopback;
порт туннеля на Koara тоже привязан к loopback. БД, API эмулятора и команды
сбоев наружу не маршрутизируются. Команды находятся в [README](../README.md#публичный-стенд).

## Темы и удобство интерфейса

Тёмная тема включается при первом запуске; светлая и серая доступны в шапке
и на экране входа. Выбор сохраняется в браузере, синхронизируется между вкладками
и не сбрасывается после выхода. Контраст ключевых элементов входа проверен
автоматически. Мобильная шапка, карточки, сворачиваемые фильтры, история
и экран сверки проверены через IAB. Цветовые токены и используемые Button, Input, Textarea, Select и Badge
перенесены из Base локально. Общими стилями владеет ui/, API не менялся.
Select использует Radix, отправка FormData и required сохраняются.
На публичном экране 390 px меню всех трёх тем помещается по ширине;
отступ стрелки от края — 17 px вместе с рамкой. Происхождение и адаптация
указаны в [описании UI](../frontend/src/ui/README.md).

## Вывод Mini-CRM из эксплуатации

На Firebat1 удалены прежний checkout `/opt/dev/projects/mini-crm`, два тома БД,
старый tunnel unit и его три SSH key/known-hosts файла. На Koara удалены прежняя
учётка туннеля, её home и sshd-конфигурация, старый Nginx vhost.
Исходники Mini-CRM сохранены в прежнем GitHub-репозитории на `167403d`.

Действующий Xray читает сертификат домена из `/etc/xray/tls/mini-crm`;
этот runtime-каталог сохранён. Certbot обновляет его через
`/etc/letsencrypt/renewal-hooks/deploy/demo-certificate`. Общий Xray
не перезапускался. У нового приложения собственные учётка, ключ и unit туннеля.
