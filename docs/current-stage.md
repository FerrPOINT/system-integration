# Текущая стадия

SI-00–SI-05 реализованы и проверены на Firebat1. Критерии всех 20 требований
связаны со сценариями TC-01–TC-15 в [матрице требований](requirements.md)
и [плане приёмки](test-cases.md).

## Рабочая среда

Разработка и проверки выполняются в `/opt/dev/system-integration` на `firebat1`.
Исходники и все 19 Markdown-документов опубликованы в GitHub. Исходное ТЗ
сверено по SHA-256; его содержимое не изменялось.

Итоговый интерфейс — `15775e1`. Нагрузка, восстановление и чистый запуск
проверены на `7de2094`. Последующая правка обновляет историю в карточке
и добавляет браузерную регрессию; исходники backend, эмулятора, контрактов,
нагрузочного runner, Compose и конфигурация Nginx совпадают по Git object ID.
После правки повторены сборка клиента, 18 браузерных сценариев и HTTP-проверка.

Стенд доступен на loopback Firebat1: frontend `19573`, API `19580`,
эмулятор `19581`, PostgreSQL `19532`. Для доступа с компьютера используется
SSH forwarding. Публичный домен в этот объём не входит.

## Внешняя очередь под нагрузкой

На момент независимой сверки из 10865 заданий измерительного окна
15 имели внешний итог, 10850 ожидали его: 4 уже приняты эмулятором,
остальные ещё ожидали доставки. p95 от создания до исполнения среди завершённых —
183.1 с. Ошибок независимой проверки нет, прогресс исполнения подтверждён.
При интенсивном создании очередь растёт; время приёма и время исполнения
показываются отдельно. После фиксации отчёта выделенные нагрузочные БД
очищены штатным reset; демонстрационные БД сохранены.
