# OpenAPI

`internal-api.openapi.yaml` задаёт обмен frontend и backend.
`external-exchange.openapi.yaml` задаёт обмен backend и эмулятора.
Правила состояний и отказов находятся в [аналитике](../docs/analysis.md).

- Меняйте операцию в её схеме. Стабильный `operationId` задаёт имя
  сгенерированного метода. Тег определяет интерфейс контроллера.
- Для нового поля определите обязательность, отсутствие и `null`. Для
  ошибки укажите HTTP-статус и машинный код. Сгенерированные файлы
  восстанавливаются из YAML.
- После правки прогоните обе сборки и контрактные проверки по
  [инструкции](../README.md#сборка-и-проверки).
