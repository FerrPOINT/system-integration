# OpenAPI

`internal-api.openapi.yaml` задаёт обмен frontend и backend.
`external-exchange.openapi.yaml` задаёт обмен backend и эмулятора.
Правила состояний и отказов находятся в [аналитике](../docs/analysis.md).

- Меняйте операцию в её схеме. Стабильный `operationId` задаёт имя
  сгенерированного метода. Тег определяет интерфейс контроллера.
- Для нового поля определите обязательность, отсутствие и `null`. Для
  ошибки укажите HTTP-статус и машинный код. Сгенерированные файлы
  восстанавливаются из YAML.
- После правки прогоните обе сборки и контрактные проверки по
  [инструкции](../README.md#сборка-и-проверки).

## Сессия и команды

/api/csrf возвращает токен и userId его владельца: null без сессии.
Frontend проверяет владельца и поколение сессии перед изменяющим запросом.
При изменении этого ответа одновременно обновляйте SessionController,
генерацию клиента и тесты смены пользователя между вкладками.
Идемпотентность принадлежит команде, а CSRF — текущей сессии; не объединяйте их.

## Длина и условные поля

Строковые minLength/maxLength означают Unicode code points. Partial
templates/java/beanValidationCore.mustache заменяет только string Size,
arrays/numbers остаются upstream. При upgrade сравнивайте partial с upstream.
Orval генерирует ограничения полей UI: название, причина, количество и логин. reconciliationId обязателен
для решений задания и запрещён для ACKNOWLEDGE_FEED_ISSUE; IssueCommands
проверяет это условие на сервере.
