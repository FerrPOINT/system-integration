# Backend

Java 25 и Spring Boot. Держите HTTP, прикладные операции и SQL в модуле
соответствующего сценария. Контроллер реализует интерфейс из OpenAPI.
Прикладная операция владеет правилами и транзакцией. Репозиторий владеет SQL.

- Модуль заданий владеет записью, очередью и историей. Модуль обмена
  вызывает его операции и обращается к эмулятору вне транзакции PostgreSQL.
- Эмулятор запускается отдельно и пишет в свою БД. Flyway ведёт миграции
  каждого процесса с `V1__...`. Применённые миграции сохраняются,
  демоданные загружаются отдельной командой.
- Тесты Spring MVC и PostgreSQL размещайте в `src/test/`.
  Команды сборки и тестов приведены в [README](../README.md#сборка-и-проверки).
